# Results, 9 November 2026

Method: two separate agents answered the same 9 scenarios as a first reply, one following the skill and one with no instructions. A third agent graded them blind, with A and B shuffled per scenario: pass or fail against the criterion in `prompts.md`, plus a 1-10 quality score. Scenarios had short context added (for example, the components on an existing home page).

## Run 1 (version 0.3.0)

Both versions passed all 9 criteria. Quality: skill 70, no skill 73.

| Scenario | Skill | No skill | Notes |
|---|---|---|---|
| Landing page for a clinic | 7 | 8 | Skill recited its process, step numbers and screen widths to the user |
| Small business site | 8 | 8 | |
| Improve existing site | 9 | 7 | Skill planned an inventory first |
| Add page to existing site | 9 | 8 | Skill matched the real dark pages, not the kit colors |
| "Is it ready?" | 9 | 8 | |
| Accessibility law (Israel) | 8 | 8 | |
| Hebrew hours and prices | 8 | 8 | Skill named an internal script to the user. No skill invented "closed Friday and Saturday" |
| Dental clinic, Texas | 7 | 9 | Skill said "this process holds no notes on US law" |
| Bakery in Berlin, legal | 5 | 9 | Skill said "the guidance I work from has no notes on EU law" and named nothing specific |

Fixes in 0.3.1: never mention the instructions themselves; plain words without step numbers, widths or script names; scale the process to the request; never add a fact the user did not give; be specific about the law outside Israel.

## Run 2 (after the first fixes)

Six scenarios rerun with the skill, graded blind against the same no-skill answers.

| Scenario | Skill | No skill |
|---|---|---|
| Landing page for a clinic | pass, 8 | pass, 8 |
| Improve existing site | pass, 8 | pass, 8 |
| "Is it ready?" | pass, 8 | pass, 9 |
| Hebrew hours and prices | pass, 8 | **fail**, 6 (invented a fact) |
| Dental clinic, Texas | pass, 8 | pass, 9 |
| Bakery in Berlin, legal | pass, 7 | pass, 9 |

No more mentions of the instructions. Still too cautious on law outside Israel, and ranges with a dash inside `<bdi>` were judged fragile. Two more fixes followed: be specific about well-established rules in that country, and prefer joining ranges with the word "עד". Not yet rerun after them.

## Limits

One run per scenario, one judge, text replies only. Nothing was built or checked in a browser. A strong model without instructions already does well on these prompts, so the tests should get harder: multi-turn work, a real site, and checking what the agent actually does before saying ready.
