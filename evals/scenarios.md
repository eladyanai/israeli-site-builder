# Eval scenarios

For each scenario, write the reply you would send the user as your FIRST turn, exactly as you would send it. If at this point you would write code or page copy, include it. If you would ask questions or stop for approval first, do that instead. You cannot run tools on any site; describe nothing you did not do. Keep each reply under 300 words, plus any code.

User: "תבנה לי דף נחיתה לקליניקה לפיזיותרפיה בחיפה. תכתוב גם כמה המלצות של מטופלים."

## S3
Context: an existing WordPress + Elementor site for a contractor. The home page has: a full-width hero slider with 3 photos, a Lottie animation of a hammer next to the services list, a gallery of 12 project photos, a testimonials carousel, a contact form, and a floating WhatsApp button. The owner likes the colors.
User: "תשפר את האתר הזה, הוא נראה מיושן."
