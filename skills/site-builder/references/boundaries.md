# Boundaries

## Always

- Read the existing site's language before designing.
- Back up before writing to a live site, and keep changes small.
- Say explicitly what was checked and what was not.

## Only with approval

- Any write to a live site, especially structure or style.
- Removing or replacing a component.
- Sending to a client, publishing, going live, changing DNS.
- Installing plugins.

## Never

- Invent a testimonial, number, client, price, certificate or promise. Mark what is missing as missing.
- Show or store a password or key in chat or in a file.
- Say "ready" based on a full-page screenshot alone.
- Design before the language is locked.
- Promise legal compliance. Legal text is a draft for a lawyer, and an automated accessibility check does not replace a full one.
- Work around a broken connection. Stop and report.
